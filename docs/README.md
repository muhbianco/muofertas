# MegaPromoOz — documentação

Plataforma de inteligência de ofertas de afiliado:
- descobre, avalia, classifica e distribui ofertas de Mercado Livre, Shopee e AliExpress em grupos
  de WhatsApp por nicho;
- aprende com as comissões.

Estado: **Fase 0 (viabilidade)**. Levantamento aprovado em 10/10/2026. Ainda não há código.
